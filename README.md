# Chatrix — پروژه Android (TWA)

این پروژه یک **Trusted Web Activity** واقعیه، نه یک WebView ساده مثل Median. تفاوتش دقیقاً همون چیزیه که باعث می‌شه نوتیفیکیشن پس‌زمینه کار کنه: این اپ محتوا رو با موتور واقعی **Chrome** (که رو گوشیت نصبه) نشون می‌ده — همون Service Worker و Push API که تو مرورگر امتحان کردی و جواب داد، اینجا هم عیناً همونه.

## قدم‌های build (دقیقاً به همون روش AFVPN، با GitHub Actions)

### ۱. ریپازیتوری بساز و پروژه رو push کن
همون روش Termux قبلی: ریپازیتوری جدید تو GitHub بساز (مثلاً `chatrix-app`)، این پوشه رو داخلش push کن.

### ۲. دو تا Secret اضافه کن (این بار aar لازم نداریم، پس این قسمت ساده‌تره)
برو تو ریپازیتوری → **Settings → Secrets and variables → Actions → New repository secret**، دو تا secret بساز:

| اسم Secret | مقدار |
|---|---|
| `KEYSTORE_BASE64` | محتوای فایل `keystore_base64.txt` که برات فرستادم (کامل کپی/پیست کن) |
| `KEYSTORE_PASSWORD` | همون پسوردی که جدا برات نوشتم |

⚠️ این پسورد و فایل کلید امضای رسمی اپته — اگه یه روز بخوای نسخه جدید همین اپ رو منتشر کنی، باید دقیقاً همین کلید رو دوباره استفاده کنی (وگرنه اندروید نسخه جدید رو "متفاوت" می‌بینه و آپدیت روی نسخه قبلی نمی‌شینه). جایی امن (مثلاً پیام خصوصی به خودت در تلگرام Saved Messages) نگهش دار.

### ۳. صبر کن build تموم بشه، APK رو دانلود و نصب کن
دقیقاً مثل AFVPN: تب **Actions**، صبر کن تیک سبز بخوره، برو تو build، بخش **Artifacts** → `chatrix-release-apk` رو دانلود کن، اکسترکت کن، نصب کن.

### ۴. آخرین قدم — انتشار assetlinks.json (این یکی روی گیت‌هاب نیست، روی خود دامنه chatrix)
تا این فایل رو منتشر نکنی، اپ کار می‌کنه ولی بالای صفحه یک نوار آدرس کوچیک نشون می‌ده (چون Chrome هنوز مطمئن نشده اپ واقعاً صاحب اون دامنه‌ست).

داخل پروژه وب chatrix (همونی که deploy کردی)، یک فایل بساز در مسیر:
```
public/.well-known/assetlinks.json
```
با این محتوای دقیق:
```json
[{
  "relation": ["delegate_permission/common.handle_all_urls"],
  "target": {
    "namespace": "android_app",
    "package_name": "com.chatrix.app",
    "sha256_cert_fingerprints": ["64:FD:06:2D:56:49:B2:25:30:FE:30:64:B3:88:60:BC:07:52:76:48:97:D5:C7:E9:90:6E:AF:0D:FC:1F:6A:62"]
  }
}]
```
بعد دوباره deploy کن (هر جا که chatrix رو host کردی). بعد از اینکه این فایل روی آدرس `https://a54075-c059.e.jrnm.app/.well-known/assetlinks.json` در دسترس باشه، اپ رو پاک نصب کن (uninstall/reinstall) — نوار آدرس محو می‌شه و کاملاً native به‌نظر می‌رسه.

## نکته درباره سرور (server.js)
برای اینکه نوتیفیکیشن پس‌زمینه همیشه کار کنه، `server.js` باید **۲۴ ساعته روشن بمونه** (چون داره به‌صورت زنده گوش می‌ده به پیام‌های جدید تو Firestore). اگه هاستی که استفاده می‌کنی بعد از چند دقیقه بی‌کاری می‌خوابه، نوتیفیکیشن‌ها موقع خواب سرور نمی‌رسن. اگه مطمئن نیستی هاستت این‌طوریه یا نه، بگو کجا deploy کردی تا چک کنم.
